# Contrato de `data-testid`

Todo selector de test usa `data-testid` (constitución V). Renombrar o quitar uno es un cambio incompatible.

| Identificador | Elemento |
|---|---|
| `app-header` | Cabecera fija. |
| `nav-home` / `nav-series` / `nav-movies` / `nav-new` / `nav-my-list` | Enlaces de navegación. |
| `nav-menu-toggle` | Botón del menú desplegable en móvil. |
| `search-toggle` / `search-input` | Lupa y campo de búsqueda. |
| `notifications-toggle` / `notifications-panel` / `notification-item` | Icono, panel y aviso (repetido). |
| `profile-menu-toggle` / `profile-menu` / `profile-option` / `sign-out` | Menú de perfil, perfil elegible (repetido) y cierre de sesión. |
| `hero` / `hero-play` / `hero-more-info` | Título destacado y sus botones. |
| `row` / `row-title` | Fila y su nombre (repetido). |
| `row-prev` / `row-next` | Flechas de la fila. |
| `top10-rank` | Número grande de la fila Top 10. |
| `title-card` | Tarjeta (repetida). |
| `card-preview` | Previsualización ampliada. |
| `preview-play` / `preview-add` / `preview-like` / `preview-more` | Acciones de la previsualización. |
| `title-modal` / `modal-dialog` / `modal-close` | Contenido del detalle, diálogo base del modal y botón de cierre. |
| `season-select` / `episode-item` | Selector de temporada y episodio (repetido). |
| `similar-title` | Título similar (repetido). |
| `add-to-list` | Botón `+` / `✓`. |
| `my-list-empty` | Mensaje de Mi lista vacía. |
| `browse-empty` | Mensaje de vista sin filas (p. ej. perfil Infantil sin contenido). |
| `search-results` / `search-empty` | Cuadrícula de resultados y mensaje sin resultados. |
| `profile-card` | Perfil en la pantalla de selección (repetido). |
| `player` / `player-play` / `player-volume` / `player-progress` / `player-fullscreen` / `player-back` | Reproductor y controles. |
